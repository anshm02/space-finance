# Space Money 🚀

A personal finance management (PFM) tool to track spending, manage budgets, and monitor financial health. Built with a Python FastAPI backend and a React Native mobile app.

## Quick Start

### Backend (API)

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```
*Runs on http://localhost:8000*

### Mobile App

```bash
cd mobile
npm install
npm start
```
*Scan the QR code with Expo Go (iOS/Android)*
